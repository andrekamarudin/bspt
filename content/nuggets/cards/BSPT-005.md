# Stop watching. Learn by doing.

> **Tell a friend:** If you can't try it, you probably haven't learned it yet.

**Human problem:** You finish a tutorial feeling informed, then freeze when you need to apply it alone.

**Byte-size ProTip:** Turn any explanation into a short realistic exercise, a rubric, feedback and a second attempt.

## The before → after moment

**Safe fictional setup:** Skill: writing a concise project update after a missed milestone.

**Copy/paste demo prompt** (works in an ordinary text chat):

```text
Teach me to write a useful project status update. Don't give a lecture first. Create one realistic, fictional 4-line situation with an overdue milestone and uncertain cause. Ask me to write a 3-sentence update. Grade my attempt on accuracy, ownership, and next action. Give one concrete improvement and a second mini challenge. Do not write the answer before I try.
```

**What the learner should notice:** The model shifts from lecturer to practice partner; the learner must generate an answer.

## Now let them try

Replace status updates with one skill you actually need this week; complete the second attempt.

**Evidence of learning:** The learner improves the second response according to the rubric.

**Integrity guardrail:** AI grading is feedback, not formal certification; benchmark critical skills against a human or known standard.
